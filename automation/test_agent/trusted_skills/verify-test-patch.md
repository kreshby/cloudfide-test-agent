# verify-test-patch v1.0.0
Consume only the supplied trusted host verification summary. Distinguish baseline
from patched execution. Failure, timeout, unavailable, or not-run cannot become
success. Never invent collected tests, exit codes, or execution. Recommend accept,
reject, or unavailable with a short interpretation. This recommendation is advisory:
it cannot manufacture, replace, or override HostResult or the host's final verdict.
Automatic repair is disabled.
