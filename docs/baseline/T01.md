## Ordinary CI and verified upstream pins

The workflow runs on pull requests targeting `main` (opened, synchronize,
reopened, ready_for_review) and pushes to `main`/`test-agent-workflow`. The branch
push trigger permits validation without modifying `main`. Both jobs use literal
`runs-on: ubuntu-24.04`, a ten-minute timeout, and only `contents: read`.

Each pin was verified against the official `actions` repository's release API,
resolved commit API, remote tag via `git ls-remote`, and `action.yml` at that SHA:

| Official upstream | Release | Verified full commit SHA |
| --- | --- | --- |
| [actions/checkout](https://github.com/actions/checkout/commit/3d3c42e5aac5ba805825da76410c181273ba90b1) | v7.0.1 | `3d3c42e5aac5ba805825da76410c181273ba90b1` |
| [actions/setup-node](https://github.com/actions/setup-node/commit/949feb2413d6458794dcd2491c4babbbce0c15c1) | v7.1.0 | `949feb2413d6458794dcd2491c4babbbce0c15c1` |
| [actions/setup-python](https://github.com/actions/setup-python/commit/5fda3b95a4ea91299a34e894583c3862153e4b97) | v7.0.0 | `5fda3b95a4ea91299a34e894583c3862153e4b97` |
| [actions/upload-artifact](https://github.com/actions/upload-artifact/commit/cf430e030ddbb5b0abf93d22962f4752f3646cd9) | v7.0.2 | `cf430e030ddbb5b0abf93d22962f4752f3646cd9` |

Checkout disables credential persistence. Node automatic caching is disabled;
neither setup action requests a cache. CI invokes no model or custom agent, uses
no provider secrets, grants no write permissions, and starts no database service.
Test/typecheck/coverage steps still run after another check fails if installation
succeeded; failures remain job failures.

Only `frontend/coverage/coverage-summary.json` and
`backend/coverage/coverage.json` are eligible for upload, one file per artifact,
with one-day retention and a 128 KiB cap per file. There are no wildcard/directory
uploads; HTML reports, dependency trees, environments, build outputs, images,
credentials, models, and caches are excluded by the explicit file list. CI
records the checked-out SHA/tool versions in logs and names artifacts with the
triggering SHA. JSON output selection does not alter the coverage denominator.
